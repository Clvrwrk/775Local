# 775 Local

**775 Directory** — the local business finder for Northern Nevada (area code 775), California border to the Utah line.

> Who actually shows up.

Not a newspaper. A directory: claimed listings, neighborhood mail, Featured shops, and “near me” search that knows Fernley from Fallon.

**Canonical product URL:** [775Directory.com](https://775directory.com)
